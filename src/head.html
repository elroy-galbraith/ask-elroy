What this is

A retrieval-augmented agent over a fixed corpus that Elroy wrote about his own work. It exists for two reasons: to answer a recruiter's questions at 11pm without him, and to be the sample rather than the description — a hiring manager can read the trace on any answer and see exactly how it was produced.

Pipeline

  • Chunk. The corpus is split at paragraph and list-item level into … passages, each carrying its parent document and section title. Small chunks retrieve precisely; the title travels with them so context is not lost.
  • Embed. all-MiniLM-L6-v2 runs in your browser via ONNX Runtime — WebGPU where the browser has it, WASM where it does not, an older runtime where that fails, and BM25 alone if all three do. The index is built on page load, so nothing is precomputed on a server and no text you type leaves the page during retrieval.
  • Retrieve, hybrid. BM25 lexical scoring and dense cosine similarity run independently, then fuse by reciprocal rank. Dense alone misses acronyms and proper nouns; lexical alone misses paraphrase. Fusion needs no tuned weight, which is why it is used here rather than a weighted blend.
  • Gate. If the best dense similarity falls under the scope threshold, the agent refuses before any model call. Out-of-scope questions therefore cost nothing and cannot be answered incorrectly.
  • Generate. The question and the retrieved passages go to a stateless proxy that holds the API key and calls Claude Haiku with a system prompt that forbids any claim not present in the passages, and requires numbered citations. The response streams back token by token.
  • Verify. Every generated answer is parsed for citations. Invalid citation indices and uncited claims are flagged in the response itself, not hidden.

Failure behaviour

Three degradation steps, all visible rather than silent. If the embedding model will not load, retrieval falls back to BM25 alone and the status bar says so. If the generator is unreachable or the session cost cap is hit, the agent returns the retrieved source passage verbatim instead of paraphrasing it. If a question falls below the scope gate, it is refused with an email address rather than answered.

Honest limitations

  • The corpus is small and self-authored. The agent is only as accurate as what Elroy wrote in it, and it has no way to know when he was too generous with himself.
  • The evaluation suite scores retrieval and refusal. It does not score whether the generated prose is good writing.
  • A first page load downloads roughly 25 MB of model weights and takes a few seconds. A production version would precompute the index and ship vectors instead — this version builds it live because watching it build is part of the point.
  • The scope gate is calibrated against a suite Elroy also wrote. See the sweep in the Evaluation tab for what other settings would cost.

Stack

One HTML file, no build step, no framework. transformers.js for in-browser embeddings, BM25 and RRF written by hand, a Cloudflare Worker for the key-holding proxy, Claude Haiku for generation.
